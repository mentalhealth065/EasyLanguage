# 🌍 Trilingo – Learn French, Arabic & Chinese together

A single-file web app (no install, no build) that runs on phones and laptops.
All instructions, meanings and pronunciations are in English.

**Features:** 10 modules (alphabet sounds → numbers → greetings → … → survival phrases), emoji pictures,
🔊 audio, language-similarity tips, recap before each new module, exam after each module (70% to unlock the next),
daily / weekly / monthly tasks, progress saved on the device.

## Run locally
Open `index.html` in any browser.

## Publish free on GitHub Pages
1. Create a repo, upload `index.html` and `README.md`.
2. Settings → Pages → Branch: `main` / root → Save.
3. Open `https://<your-username>.github.io/<repo>/` on phone or laptop.

## Add words
Edit the `M` array in `index.html`:
`["emoji","English","French","FR sound","Arabic","AR transliteration","Chinese","pinyin"]`
